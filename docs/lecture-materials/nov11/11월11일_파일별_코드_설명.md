# 11월 11일 강의 코드별 설명

이 문서는 강의에서 확인한 코드와 다운로드 프로젝트의 실행용 재구성 코드를 구분한다.

## 1. ThemeProvider.tsx

위치: `src/components/ThemeProvider.tsx`

```tsx
'use client';

import { createContext, useEffect, useState, type ReactNode } from 'react';

type Theme = 'light' | 'dark';

type ThemeContextValue = {
  theme: Theme;
  toggleTheme: () => void;
};

export const ThemeContext = createContext<ThemeContextValue>({
  theme: 'light',
  toggleTheme: () => {},
});

export default function ThemeProvider({ children }: { children: ReactNode }) {
  const [theme, setTheme] = useState<Theme>('light');

  useEffect(() => {
    if (typeof window !== 'undefined') {
      document.documentElement.dataset.theme = theme;
    }
  }, [theme]);

  const toggleTheme = () => {
    setTheme((current) => (current === 'dark' ? 'light' : 'dark'));
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
}
```

### 한 줄씩 이해하기

- `'use client'`: 상태 Hook과 Effect를 쓰는 Client Component 경계를 선언한다.
- `createContext`: theme과 toggleTheme을 하위 트리에서 공유할 Context 객체를 만든다.
- `ThemeContextValue`: Context에 들어갈 값의 타입을 지정한다.
- `useState<Theme>('light')`: 상태가 `light` 또는 `dark`만 되도록 제한한다.
- `useEffect(..., [theme])`: theme이 바뀔 때마다 HTML 속성을 업데이트한다.
- `document.documentElement`: 현재 문서의 최상위 `<html>` 요소다.
- `dataset.theme`: `<html data-theme="dark">` 같은 data 속성을 설정한다.
- `setTheme(current => ...)`: 이전 상태를 기준으로 다음 상태를 계산한다.
- `Provider value`: 현재 theme과 변경 함수를 자식 컴포넌트에 전달한다.

## 2. ThemeStatus.tsx

위치: `src/components/ThemeStatus.tsx`

```tsx
'use client';

import { useContext } from 'react';
import { ThemeContext } from './ThemeProvider';

export default function ThemeStatus() {
  const { theme, toggleTheme } = useContext(ThemeContext);

  return (
    <div className="theme-status">
      <button
        type="button"
        className="theme-button"
        onClick={toggleTheme}
        aria-label="toggle theme"
      >
        Theme: {theme === 'dark' ? '🌙 Dark' : '🌞 Light'}
      </button>
    </div>
  );
}
```

ThemeStatus는 Context의 값을 소비하는 Consumer 역할을 한다. 버튼을 클릭하면 Provider에 전달된 `toggleTheme`가 실행된다.

## 3. RootLayout.tsx

위치: `src/app/layout.tsx`

RootLayout은 Server Component로 유지하고, 그 내부에서 Client Component인 ThemeProvider를 사용한다.

```tsx
<body>
  <ThemeProvider>
    <header>
      <ThemeStatus />
    </header>
    <main>{children}</main>
  </ThemeProvider>
</body>
```

Provider 아래의 페이지와 메뉴 컴포넌트는 같은 Context 값을 읽을 수 있다.

## 4. Gallery.tsx

위치: `src/components/gallery/Gallery.tsx`

강의의 핵심 패턴은 Client Component에서 외부 Carousel을 사용하는 것이다.

영상의 코드 형태:

```tsx
'use client';

import { useState } from 'react';
import { Carousel } from 'acme-carousel';

export default function Gallery() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <div>
      <button onClick={() => setIsOpen(true)}>View pictures</button>
      {isOpen && <Carousel items={items} />}
    </div>
  );
}
```

이 프로젝트에서는 외부 패키지의 내부 구현과 실제 CSS 파일을 확인할 수 없으므로, 실행 가능하도록 로컬 `LocalCarousel`을 작성했다. 실제 화면의 `items` 데이터 구조는 그대로 반영했다.

```tsx
const items = [
  { id: '1', src: 'https://picsum.photos/id/1015/800/600', alt: 'Landscape 1' },
  { id: '2', src: 'https://picsum.photos/id/1016/800/600', alt: 'Landscape 2' },
  { id: '3', src: 'https://picsum.photos/id/1018/800/600', alt: 'Landscape 3' },
];
```

## 5. LocalCarousel.tsx

위치: `src/components/gallery/LocalCarousel.tsx`

이 파일은 강의의 `acme-carousel`을 복제한 것이 아니라, `items` 배열을 받아 이미지 한 장씩 표시하는 학습용 대체 컴포넌트다.

- `items`: 화면에 표시할 이미지 목록
- `currentIndex`: 현재 표시하는 배열 인덱스
- `useEffect`: 자동 재생 타이머 설정과 해제
- `setCurrentIndex`: 이전/다음 버튼과 점 버튼의 선택 처리

## 6. CSS

위치: `src/components/gallery/styles.css`

영상에서 외부 패키지 스타일이 적용되지 않는 경우 로컬 CSS를 import하는 흐름을 설명했다. 이 프로젝트는 실제 패키지 CSS 대신 직접 작성한 스타일을 사용한다.

`src/app/globals.css`에는 다음 속성 선택자가 적용되어 있다.

```css
html[data-theme='light'] {
  background-color: white;
  color: black;
}

html[data-theme='dark'] {
  background-color: black;
  color: white;
}
```

프로젝트에서는 CSS 변수와 결합해 사이트 전체에 테마를 적용한다.
