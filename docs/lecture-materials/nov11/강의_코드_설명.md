# 9주차 핵심 코드 설명

## 1. Server Component와 Client Component

`src/app/[id]/page.tsx`는 **Server Component**로 게시글 데이터를 찾아 렌더링합니다. 클릭 이벤트를 처리하는 `src/ui/LikeButton.tsx`에는 파일 첫 줄의 `'use client'` 선언이 필요합니다.

## 2. props 전달

`<LikeButton likes={post.likes} />`는 서버에서 읽은 숫자를 자식 컴포넌트로 넘깁니다. LikeButton의 `{ likes }: { likes: number }`는 전달받은 props를 추출하는 타입스크립트 문법입니다.

## 3. 상태 업데이트

`const [count, setCount] = useState(likes ?? 0)`로 초기 숫자를 관리하고, `setCount((c) => c + 1)`로 이전 값 기준으로 1 증가시킵니다.

## 4. 낙관적 업데이트

버튼을 클릭하면 네트워크 요청이 끝나기를 기다리지 않고 숫자를 먼저 증가시킵니다. 강의에서는 서버 API 저장을 실제 구현하지 않았으므로 숫자가 영구 저장되지는 않습니다.

## 5. 동적 라우팅

`src/app/[id]/page.tsx`는 `/nextjs`, `/routing`처럼 가변적인 URL 경로를 처리합니다. `params`를 `await`하고 `posts.find()`로 id가 일치하는 게시글을 검색합니다. 없으면 `notFound()`.

## 6. 공통 레이아웃과 Link

`src/app/layout.tsx`는 `<html>`, `<body>`, 공통 header/footer, `{children}`을 정의합니다. Next.js의 `<Link href="...">`를 사용하여 페이지 간 이동합니다.

## 7. 파일별 체크리스트

- `src/app/page.tsx`: 목록/홈
- `src/app/counter/page.tsx`: Counter 컴포넌트 사용
- `src/components/Counter.tsx`: 클라이언트 상태 관리
- `src/app/[id]/page.tsx`: `await params`, `find`, `notFound`, props
- `src/lib/data.ts`: 게시글 샘플 데이터
- `src/ui/LikeButton.tsx`: `use client`, 상태, 클릭, 중복 클릭 방지
- `src/app/layout.tsx`: 공통 메뉴와 `children`
- `src/app/carousel`, `src/app/interleaved`: 강의에서 보인 경로를 위한 **추가 구현**
